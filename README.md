# 求职招聘小程序劳务派遣系统灵活用工APP源码搭建-ym7k

 获取源码：ym7k.com/19203/求职招聘小程序劳务派遣系统灵活用工APP源码搭建-ym7k

企业端功能全解析——招人才、招零工、招兼职与供需发布
企业端首页围绕“招人”核心需求设计，包含六大功能入口：招人才展示全职人才简历，招零工展示零工人才简历，招兼职展示兼职人才简历，招合作可发布供需信息，政策直达可发布政策文本内容，专家智库展示各行业专家信息，推荐展示后台推荐的简历。企业可根据用工类型快速筛选对应人才库提升招聘效率。

企业查看人才详情后可向人才发送邀约。邀约功能支持选择邀约时间和邀约岗位，企业从已发布职位中选择岗位设定面试或到岗时间，系统将邀约信息推送给求职者。邀约记录存储在邀约表中关联企业ID、简历ID、职位ID和邀约时间。求职者收到邀约后可在消息模块中查看并回复形成招聘互动闭环。

企业端投递模块包含五个子页面：消息盒展示职位审核信息、被查看、邀面试、不合适等系统消息；已投递展示人才投递的简历；被查看展示被企业查看过的人才简历；邀面试展示已发送面试邀请的人才简历支持在线沟通直接与求职者聊天；不合适展示被标记为不合适的人才简历。投递状态流转通过状态机管理，企业可手动更新状态并触发系统消息通知。

企业信息编辑包含基础信息和补充信息两部分。基础信息包括企业名称、所属行业、企业性质、所在地区、联系人、联系电话、短信验证码、企业简介、信用代码和营业执照。补充信息包括企业LOGO、企业规模、企业待遇、备用电话、联系邮箱和企业环境。企业提交资料后进入后端审核流程，审核失败可重新提交。审核通过后企业获得发布职位和主动沟通权限。

我的招聘模块支持发布职位、刷新职位、下架职位、修改招聘信息、分享职位和设为急招。发布职位需填写职位名称、职位类型、职位类别、薪资待遇、招聘人数、职位描述、联系人、联系电话、联系人头像、工作地址等信息。补充信息包括薪资形式、结算方式、所属工种、经验要求、学历要求、从事行业、待遇、到岗时间、年龄要求、性别要求、婚姻状况和语言要求。职位发布后支持刷新提升曝光、下架停止招聘、修改更新信息、分享给他人和设为急招优先展示。

企业可收藏感兴趣的人才简历在“我的收藏”中统一查看。消息中心展示企业与人才的所有沟通消息支持文字聊天和系统通知。消息数据存储在消息表中通过WebSocket实现实时推送确保沟通及时性。企业端功能围绕“找人才、发职位、管投递、做沟通”四大核心场景设计，完整职位管理、灵活人才邀约和高效投递管理为企业提供高效招聘工具。
